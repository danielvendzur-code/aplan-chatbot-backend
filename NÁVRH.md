# Aplan Asistent — archívny návrh

Tento súbor pôvodne obsahoval produktový návrh a demo špecifikáciu asistenta z obdobia, keď kalendár, AI a odosielanie dopytov ešte neboli napojené na produkčné služby.

**Nie je zdrojom pravdy pre aktuálnu verziu.** Pôvodný návrh zostáva dostupný v Git histórii repozitára.

Aktuálny stav a produkčné požiadavky sú zdokumentované tu:

- `PRODUCTION_CHECKLIST.md` — čo je hotové, čo ešte treba dokončiť a finálny smoke test,
- `NASADENIE.md` — Vercel, environment variables, Claude, KV, Gmail SMTP, Calendly, rate limiting a admin prístup.

Aktuálna implementácia obsahuje reálne AI odpovede, reálny backend dopytov, serverovú históriu a reálny Calendly inline embed. Pred finálnym odovzdaním treba podľa checklistu dokončiť e-mailové odoslanie Projektového štartovacieho balíka a reálne prílohy k dopytu.
